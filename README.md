# Proton pump inhibitors versus H2 receptor antagonists and acquired hypomagnesaemia in critically ill adults

Analysis code accompanying the manuscript *Proton pump inhibitors versus histamine-2 receptor antagonists and acquired hypomagnesaemia in critically ill adults: a two-database cohort study with pharmacovigilance signal analysis* (under review).

This repository contains the code used to build the time-zero cohorts, estimate the primary and sensitivity models, generate the figures, and produce the aggregate result files quoted in the manuscript. **No patient-level data are included.** MIMIC-IV and eICU-CRD are available to credentialed users through PhysioNet; FAERS is public.

## Layout

```
analysis/   analysis scripts (run order below)
results/    aggregate result files; every number quoted in the manuscript maps here
figures/    final Figure 1-6 (generated by analysis/113_revise_figures_r2.py)
```

## Data access

- **MIMIC-IV v3.1** (PhysioNet): credentialed access and a data-use agreement are required. The scripts expect the official archive at `$MIMIC_IV_ZIP` (default `data/mimic-iv-3.1.zip`), with the `mimic-iv-3.1/` directory inside the archive.
- **eICU-CRD v2.0** (PhysioNet): same access model. The scripts expect the CSV files at `$EICU_CRD_DIR` (default `data/eicu-crd-2.0`).
- **FAERS**: public; the pharmacovigilance arm queries the openFDA drug/event endpoint (query date 19 September 2026). No key is required.

Derived analysis tables (`.parquet`) are created at run time under `data/` and are not deposited, because they remain subject to the source databases' data-use agreements.

## Environment

Python 3.12. Install dependencies:

```
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Set paths if the defaults do not apply:

```
set PPI_MG_ROOT=D:\path\to\this\repository
set MIMIC_IV_ZIP=D:\path\to\mimic-iv-3.1.zip
set EICU_CRD_DIR=D:\path\to\eicu-crd-2.0
```

`PPI_MG_DATA`, `PPI_MG_RESULTS` and `PPI_MG_FIGURES` can be set to redirect intermediate data, result files and figures.

## Design notes

- **Time zero** is 24 hours after ICU admission. Patients enter at their first acid-suppressant prescription within `[-48 h, +24 h]` of admission; the exposure is the class of that first prescription. Co-prescriptions are counted only when started on or before time zero. The admission-wide drug count is not a covariate.
- **MIMIC-IV dates** are shifted per patient. Real admission year is recovered from `anchor_year_group` and `anchor_year`; scripts 105, 106, 114 and 119 do this.
- **eICU-CRD** uses unit offsets in minutes; its baseline magnesium window extends to 12 hours before admission, and hospital-clustered standard errors are used throughout.
- **Exclusivity** (one acid-suppressant class during the stay) is assessed over the whole stay. Script 114 reports the analysis with both-class patients included and exposure assigned by the first order alone.
- **FAERS** reporting odds ratios use Woolf confidence intervals. The denominator is the number of reports naming the drug; these are reporting proportions, not incidences.
